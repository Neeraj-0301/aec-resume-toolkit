How to use it

1

Import or start fresh

Paste an existing resume into the Import tab to pre-fill everything, or work top to bottom from Basic Info.

2

Fix what is flagged

Bullets are checked as you type for weak openers and missing numbers. The Job Match tab shows what a specific role asks for that you have not said yet.

3

Pick a look and export

The Design tab sets template, type and colour. Export downloads straight away — no print dialog. Save it as a named version to track the application.

A word on how the scoring works. The built-in scorer is a rules engine: it looks for structure, action verbs, numbers, and discipline keywords, and it understands a few hundred AEC synonyms so wording differences do not cost you points. It is fast, free, and completely offline — but it can still be gamed, and it cannot tell good writing from bad writing that happens to contain the right nouns.

And a word on the importer. It reads your resume by looking for section headings. It gets most of it right and some of it wrong — always walk through each tab afterwards and fix what landed in the wrong field.

If you want judgement rather than pattern-matching, the Score tab has an optional field for your own Anthropic API key. That sends your resume text to Anthropic directly from your browser and returns written feedback. It's entirely optional — the tool works fully without it.
