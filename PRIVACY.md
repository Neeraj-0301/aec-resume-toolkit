# Privacy

Short version: **nothing you type ever leaves your browser**, except the
one optional feature below.

## What this tool does

- Everything — building, scoring, job matching, PDF export, the resume
  parser — runs as JavaScript in your own browser tab. There is no backend
  server. Your resume, name, phone number, and email address are never
  transmitted anywhere.
- Drafts and saved versions are stored in your browser's `localStorage`,
  which stays on your device. Clearing your browser's site data deletes
  them permanently — there is no copy anywhere else to recover from.
- No cookies, no trackers, no analytics are currently active on this site.

## The one optional exception

If you choose to enter your own Anthropic API key (in Score mode, for
AI-scored feedback, or in the Bullet Coach, for AI-rewritten bullets), your
resume text is sent directly from your browser to Anthropic's API, using
your key. This request does not pass through any server belonging to this
site. It is entirely optional — every feature works without it — and the
key you enter is stored only in your browser, not transmitted anywhere
except to Anthropic when you use those two features.

## If this changes

If anonymous usage analytics or an accounts system are added in future,
this file will be updated before that change ships, with a clear
explanation of exactly what is collected and why. Nothing will be added
silently.
